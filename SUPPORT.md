# Support

Pine Script Agent Kit is a free community project. Choose the channel that
matches your question so people can reproduce it and keep private data safe.

## Questions and ideas

- Ask a usage question or propose an idea in [GitHub Discussions](https://github.com/trugurpala/pinescriptv6/discussions).
- Include the Pine version, chart timeframe, requested timeframes, symbol or
  market context, and the smallest reproducible example.

## Reproducible defects

Use the [issue chooser](https://github.com/trugurpala/pinescriptv6/issues/new/choose)
for broken repository checks, incorrect source links, or documentation errors.
Remove credentials, private code, customer data, and personal information.
Paste sanitized compiler messages instead of account-specific screenshots.

## Security and privacy

Do not post private code, credentials, tokens, or personal data in public.
Report sensitive problems through [SECURITY.md](SECURITY.md).

## TradingView evidence

Repository checks are `structural-only`. A stronger claim needs the exact file
hash and a matching record in `verification/tradingview.json`. Follow the
[TradingView manual verification guide](docs/tradingview-manual-verification.md).
Compilation, repaint behavior, profitability, data access, and live-trading
suitability remain separate questions.

## Response expectations

This is volunteer-maintained community infrastructure. Please provide enough
context to reproduce the question, and allow time for a maintainer or
contributor to respond.

## Türkçe kısa yönlendirme

tekrarlanabilir hatalar için [issue seçicisi](https://github.com/trugurpala/pinescriptv6/issues/new/choose)

ekleme; hassas sorunları [SECURITY.md](SECURITY.md) üzerinden bildir.
