# Roadmap

This roadmap describes sequence, not a delivery promise. A phase moves into a
published release only after its changes are merged, tagged, and recorded in the
changelog.

## Phase 1 — Reliability core

The current branch adds source-bound alert, strategy execution, and repaint
classification guidance plus public adoption and contribution documents. It
remains unreleased until it is merged and tagged. The published release remains
v1.0.0.

## Phase 2 — Daily Pine foundations

Expand source-bound coverage for types, state, history, warm-up, collections,
sessions, timeframes, symbols, data gaps, and granular request patterns.

## Phase 3 — Distribution and adapters

Strengthen host smoke tests and compatibility guidance. Add versioned,
tool-specific bundles only when build and publication evidence exists.

## Phase 4 — Community verification

Improve hash-bound TradingView records, monitor official source changes, and
review stale rules and incorrect claims. Community findings remain bounded by
their recorded file, source, environment, and date.

See [coverage](COVERAGE.md) for the active/planned boundary and the
[changelog](CHANGELOG.md) for shipped history. This roadmap gives no date or
availability promise without evidence.
