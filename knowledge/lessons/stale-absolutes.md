# Lesson: stale absolutes create confident errors

AI instruction files can repeat rules that are either false or too broad.
Examples include banning `math.avg()` and generic `input()`, replacing one
bar-state predicate with another, banning realtime strategy recalculation, and
rewriting every `request.security()` call with an HTF-specific pattern.

The correction is structural:

1. register the current official source;
2. state a narrow claim and rationale;
3. record scope and exceptions;
4. attach an evidence level and verification date;
5. test that the old absolute is rejected;
6. generate adapters only from the corrected catalog.

No private prompt, customer script, credential, or personal information was used
to create this lesson.
